What breaks without this

بدون این ابزار چه می‌سوزد

Claude Desktop is excellent — until you want other models, lower cost, or visibility into what it actually sends upstream.

Claude Desktop عالی است — تا وقتی بخواهید مدل دیگر، هزینه کمتر، یا دید به آنچه واقعاً ارسال می‌شود.

Locked to Anthropic billing قفل روی صورتحساب Anthropic Heavy agent turns with tools + huge system prompts burn tokens fast on official Claude rates. نوبت‌های سنگین با ابزار و سیستم‌پرامپت بزرگ، روی تعرفه رسمی Claude سریع می‌سوزد.
Desktop rejects non-Claude model IDs Desktop شناسه غیر Claude را رد می‌کند You can’t just paste deepseek/... into the picker. Desktop wants Anthropic-looking routes. نمی‌توانید فقط deepseek/... را در انتخابگر بگذارید؛ Desktop مسیرهایی شبیه Anthropic می‌خواهد.
Invisible system harness هارنس سیستم نامرئی Desktop ships a large system prompt + tool schemas every turn. Without a proxy you rarely see it. Desktop هر نوبت سیستم‌پرامپت بزرگ و اسکیمای ابزار می‌فرستد؛ بدون پروکسی معمولاً نمی‌بینیدش.
No clean remap / fallback story بدون نگاشت و مسیر جایگزین تمیز Switching between budget coding models and official Claude needs a local router — not manual config hacks. جابه‌جایی بین مدل‌های ارزان کدنویسی و Claude رسمی به یک مسیریاب محلی نیاز دارد، نه هک دستی کانفیگ.

What this gateway does

این درگاه چه می‌کند

Configures Claude Desktop (3P) so the model picker shows friendly labels while IDs stay Anthropic-shaped.

Claude Desktop (حالت 3P) را طوری تنظیم می‌کند که برچسب‌های خوانا ببینید، در حالی که شناسه‌ها شبیه Anthropic می‌مانند.

Runs a loopback Anthropic Messages proxy that remaps those IDs to OpenRouter (or a compatible mirror) — DeepSeek, Kimi, Qwen, Grok, official Claude, and more.

یک پروکسی محلی Messages اجرا می‌کند و آن شناسه‌ها را به OpenRouter (یا آینه سازگار) نگاشت می‌کند — DeepSeek، Kimi، Qwen، Grok، Claude رسمی و بیشتر.

Install

نصب

Download the binary for your OS. No checkout required — first run writes the default config automatically.

باینری سیستم‌عامل خود را بگیرید. نیازی به کلون ریپو نیست — اولین اجرا کانفیگ پیش‌فرض را می‌نویسد.

curl -fsSL -o claude-gateway \
  https://github.com/Danakolana/claude-gateway/releases/latest/download/claude-gateway-linux-amd64
chmod +x claude-gateway
export OPENROUTER_API_KEY=sk-or-...
./claude-gateway
curl -fsSL -o claude-gateway \
  https://github.com/Danakolana/claude-gateway/releases/latest/download/claude-gateway-darwin-arm64
chmod +x claude-gateway
xattr -d com.apple.quarantine ./claude-gateway 2>/dev/null || true
export OPENROUTER_API_KEY=sk-or-...
./claude-gateway
Invoke-WebRequest -Uri "https://github.com/Danakolana/claude-gateway/releases/latest/download/claude-gateway-windows-amd64.exe" `
  -OutFile "claude-gateway.exe"
$env:OPENROUTER_API_KEY = "sk-or-..."
.\claude-gateway.exe

First run

اولین اجرا

  1. Set OPENROUTER_API_KEY and start the binary. This guide opens in your browser; the terminal prints the same URL. OPENROUTER_API_KEY را بگذارید و باینری را اجرا کنید. این راهنما در مرورگر باز می‌شود؛ همان آدرس در ترمینال چاپ می‌شود.
  2. Choose 3P when asked (recommended). Desktop Connection settings are written for you. وقتی پرسیده شد 3P را انتخاب کنید (پیشنهادی). تنظیمات Connection دسکتاپ برایتان نوشته می‌شود.
  3. Reopen Claude Desktop (or Apply Changes). Pick a labeled model — budget remaps or official Claude. Claude Desktop را دوباره باز کنید (یا Apply Changes). مدل برچسب‌دار را انتخاب کنید — remap ارزان یا Claude رسمی.

Config path: ~/.config/claude-gateway/config.toml (Windows: %APPDATA%\claude-gateway\config.toml). Existing files are never overwritten.

مسیر کانفیگ: ~/.config/claude-gateway/config.toml (ویندوز: %APPDATA%\claude-gateway\config.toml). فایل موجود بازنویسی نمی‌شود.

Harness & system prompts

هارنس و سیستم‌پرامپت

Claude Desktop sends a large system prompt and tool list on each turn. This page reads them from the same local proxy — no extra web server.

Claude Desktop در هر نوبت سیستم‌پرامپت بزرگ و فهرست ابزار می‌فرستد. این صفحه همان را از پروکسی محلی می‌خواند — بدون وب‌سرور جدا.

inspect off

Enable capture (off by default for privacy), then use Desktop once and refresh:

برای حریم خصوصی پیش‌فرض خاموش است. روشن کنید، یک‌بار با Desktop حرف بزنید، بعد Refresh:

[proxy]
inspect_prompts = true

Or: export CLAUDE_GATEWAY_INSPECT_PROMPTS=1 then restart.

یا: export CLAUDE_GATEWAY_INSPECT_PROMPTS=1 و ری‌استارت.

Useful knobs

تنظیمات کاربردی

mode = "local" (default) remaps any Desktop ID. mode = "direct" talks to OpenRouter’s Anthropic API without the local proxy — official anthropic/claude-* only.

mode = "local" (پیش‌فرض) هر شناسه Desktop را remap می‌کند. mode = "direct" بدون پروکسی محلی به API سازگار Anthropic در OpenRouter می‌رود — فقط anthropic/claude-*.

Cost helpers: prefer_cheapest, ensure_prompt_cache, thinking_policy, provider sort = "price". See models status in the terminal for live prices.

کمک‌هزینه: prefer_cheapest، ensure_prompt_cache، thinking_policy، و sort = "price". برای قیمت زنده در ترمینال: models status.

Served from your local proxy · loopback only · secrets stay in env vars سرو از پروکسی محلی · فقط loopback · کلیدها در متغیر محیطی
