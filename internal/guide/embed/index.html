How it works

چطور کار می‌کنه

Desktop only accepts Anthropic-looking model IDs. This gateway keeps those IDs, shows readable names in the picker, and remaps each request to the real OpenRouter model.

دسکتاپ فقط شناسه‌هایی شبیه Claude رو قبول می‌کنه. این برنامه همون شناسه‌ها رو نگه می‌داره، تو لیست مدل اسم خوانا می‌ذاره، و هر درخواست رو می‌فرسته به مدل واقعی روی OpenRouter.

1

Run it locally

روی سیستم خودت اجراش کن

Start the binary with your OpenRouter key. This page opens in the browser. Nothing leaves your machine except the model call itself.

باینری رو با کلید OpenRouter اجرا می‌کنی. همین صفحه تو مرورگر باز می‌شه. از سیستم خودت چیزی بیرون نمی‌ره، غیر از همون درخواستی که باید بره سمت مدل.

2

It wires Desktop for you

دسکتاپ رو برات تنظیم می‌کنه

Pick 3P when asked. Connection settings and model labels are written automatically — no hand-editing JSON.

وقتی پرسید، گزینه‌ی 3P رو بزن. تنظیمات اتصال و اسم مدل‌ها خودش نوشته می‌شه؛ لازم نیست فایل JSON رو دستی عوض کنی.

3

Pick a model, chat as usual

مدل رو انتخاب کن و مثل همیشه چت کن

Reopen Claude Desktop. The picker shows names you recognize. Cheap remaps and official Claude both live in the same list.

دسکتاپ رو یه بار ببند و باز کن. تو لیست، اسم‌هایی می‌بینی که می‌فهمی. هم مدل ارزون هست، هم Claude رسمی — تو یه لیست.

Why bother?

بدون این، گیر چی می‌افتی؟

Claude Desktop is a great client. It just wasn’t built to let you pick cheaper models, or to show you the giant prompt it ships on every turn.

خود Claude Desktop عالیه. مشکل اینه که برای مدل ارزون ساخته نشده، و معمولاً هم نمی‌ذاره ببینی هر بار دقیقاً چه پرامپت گنده‌ای داره می‌فرسته بالا.

Every turn at Anthropic prices هر پیام با قیمت Anthropic حساب می‌شه Agent chats with tools and a huge system prompt burn tokens fast on official Claude rates. چت‌های سنگین با ابزار و پرامپت بلند، با تعرفه‌ی رسمی Claude خیلی زود می‌سوزه.
Desktop rejects non-Claude IDs مدل غیر Claude رو راه نمی‌ده You can’t paste deepseek/... into the picker. It wants Anthropic-shaped routes. نمی‌تونی deepseek/... رو بندازی تو لیست مدل. دسکتاپ فقط مسیر شبیه Anthropic می‌خواد.
The system prompt stays invisible پرامپت سیستم رو نمی‌بینی Desktop sends a large system prompt plus tool schemas every turn. Without a proxy, you rarely see it. هر بار یه پرامپت بلند و لیست ابزار همراه پیام می‌ره. بدون پروکسی معمولاً خبر نداری داخلش چیه.
No clean cheap / official switch سوییچ تمیز بین ارزون و رسمی نداری Jumping between a budget coding model and official Claude needs a local router — not config hacks. بین مدل ارزون کدنویسی و Claude رسمی، یه روتر روی سیستم خودت لازم داری — نه دستکاری الکی کانفیگ.

تو لیست مدل چی می‌بینی

Install

نصب

Grab the binary for your OS. No git clone. First run writes the default config if you don’t already have one.

باینری سیستم‌عاملت رو بگیر. لازم نیست ریپو کلون کنی. اگه کانفیگ نداشته باشی، اولین اجرا خودش می‌نویسه.

curl -fsSL -o claude-gateway \
  https://github.com/Danakolana/claude-gateway/releases/latest/download/claude-gateway-linux-amd64
chmod +x claude-gateway
export OPENROUTER_API_KEY=sk-or-...
./claude-gateway

ARM64 Linux: download claude-gateway-linux-arm64 instead.

لینوکس ARM64: به‌جاش claude-gateway-linux-arm64 رو بگیر.

curl -fsSL -o claude-gateway \
  https://github.com/Danakolana/claude-gateway/releases/latest/download/claude-gateway-darwin-arm64
chmod +x claude-gateway
xattr -d com.apple.quarantine ./claude-gateway 2>/dev/null || true
export OPENROUTER_API_KEY=sk-or-...
./claude-gateway

Intel Mac: use claude-gateway-darwin-amd64. Check with uname -m.

مک اینتل: claude-gateway-darwin-amd64. با uname -m ببین کدومی.

Invoke-WebRequest -Uri "https://github.com/Danakolana/claude-gateway/releases/latest/download/claude-gateway-windows-amd64.exe" `
  -OutFile "claude-gateway.exe"
$env:OPENROUTER_API_KEY = "sk-or-..."
.\claude-gateway.exe

SmartScreen may warn on an unsigned exe — More info → Run anyway if you trust the GitHub release. Leave the terminal open while the proxy runs. ARM Windows: claude-gateway-windows-arm64.exe.

اگه SmartScreen گیر داد و به فایل گیت‌هاب اعتماد داری: More info، بعد Run anyway. ترمینال رو نبند تا پروکسی کار کنه. ویندوز ARM: claude-gateway-windows-arm64.exe.

First run

اولین بار که اجرا می‌کنی

  1. Set OPENROUTER_API_KEY and start the binary. This guide opens in your browser; the terminal prints the same URL. کلید OPENROUTER_API_KEY رو بذار و برنامه رو اجرا کن. همین راهنما تو مرورگر باز می‌شه؛ همون آدرس تو ترمینال هم می‌آد.
  2. Choose 3P when asked (recommended). Desktop Connection settings are written for you. Non-interactive runs default to 3P. پرسید Desktop رو کجا تنظیم کنه، 3P رو بزن — این گزینه‌ی پیشنهادیه. تنظیمات اتصال خودش نوشته می‌شه. اگه ترمینال تعاملی نباشه، خودش می‌ره روی 3P.
  3. Quit and reopen Claude Desktop (or Apply Changes). Pick a labeled model — budget remap or official Claude. دسکتاپ رو کامل ببند و دوباره باز کن (یا Apply Changes). مدل رو از لیست انتخاب کن — ارزون یا Claude رسمی.

Config path: ~/.config/claude-gateway/config.toml on macOS/Linux, %APPDATA%\claude-gateway\config.toml on Windows. An existing file is never overwritten.

مسیر کانفیگ روی مک و لینوکس: ~/.config/claude-gateway/config.toml — ویندوز: %APPDATA%\claude-gateway\config.toml. اگه فایل از قبل باشه، دستش نمی‌زنه.

Useful knobs

تنظیماتی که واقعاً به درد می‌خورن

You don’t need to touch these on day one. When you do, they live in config.toml.

روز اول لازم نیست دست به اینا بزنی. وقتی خواستی، همه‌شون تو config.toml هستن.

local vs direct حالت local یا direct

mode = "local" (default) remaps any Desktop ID through this proxy. mode = "direct" talks to OpenRouter’s Anthropic API with no local proxy — official anthropic/claude-* only.

mode = "local" پیش‌فرضه: هر مدل دسکتاپ از همین برنامه رد می‌شه و می‌تونه ارزون باشه. mode = "direct" بدون پروکسی محلی می‌ره OpenRouter — فقط مدل‌های رسمی anthropic/claude-*.

Spend less per turn خرج هر پیام کمتر بشه

prefer_cheapest, ensure_prompt_cache, thinking_policy, and provider sort = "price". Live prices: models status.

prefer_cheapest ارزون‌ترین مدل مناسب رو برمی‌داره. ensure_prompt_cache سعی می‌کنه پرامپت تکراری ارزون‌تر حساب بشه. thinking_policy جلوی توکن فکر کردن اضافه رو می‌گیره. قیمت زنده: models status.

OpenRouter won’t open اگه OpenRouter باز نشد

Point at a compatible mirror with OPENROUTER_BASE_URL or [providers.openrouter] base_url in config. Same API, different host.

می‌تونی آدرس یه آینه‌ی سازگار رو بدی: متغیر OPENROUTER_BASE_URL، یا تو کانفیگ [providers.openrouter] base_url. همون API، فقط آدرس فرق می‌کنه.

Add your own model مدل خودت رو اضافه کن

A [models.*] block needs a desktop_id that looks like claude-* or anthropic/claude-*, plus a routing rule. Re-run the binary so Desktop refreshes.

یه بلوک [models.*] بذار. desktop_id باید شبیه claude-* یا anthropic/claude-* باشه، به‌علاوه‌ی یه قانون routing. دوباره اجرا کن تا دسکتاپ لیست رو عوض کنه.

What Desktop actually sends

دسکتاپ واقعاً چی می‌فرسته

Each turn includes a large system prompt and a tool list. This page reads them from the same local proxy — no extra server. Capture is off by default, on purpose.

هر پیام، یه پرامپت سیستم بلند و لیست ابزار هم همراهشه. این صفحه همون‌ها رو از همین پروکسی محلی می‌خونه؛ وب‌سرور جدا نمی‌خواد. ضبط عمداً پیش‌فرض خاموشه.

inspect off

Turn capture on, send one Desktop message, then refresh:

ضبط رو روشن کن، یه پیام از دسکتاپ بفرست، بعد تازه‌سازی:

[proxy]
inspect_prompts = true

Or: export CLAUDE_GATEWAY_INSPECT_PROMPTS=1 and restart.

یا همین: export CLAUDE_GATEWAY_INSPECT_PROMPTS=1 و برنامه رو از نو اجرا کن.

Questions people actually ask

سؤال‌هایی که معمولاً پیش میاد

Where does the API key go?کلید API رو کجا بذارم؟

In the environment: OPENROUTER_API_KEY. Do not put secrets in TOML — that file is plain text on disk.

تو متغیر محیطی: OPENROUTER_API_KEY. کلید رو نذار داخل فایل کانفیگ؛ اون فایل روی دیسک، متن ساده‌ست.

Is this patching Claude Desktop?این برنامه دسکتاپ رو هک می‌کنه؟

No. It uses documented 3P gateway Connection settings. It does not patch binaries or bypass Anthropic login.

نه. از تنظیمات رسمی حالت 3P استفاده می‌کنه. باینری Claude رو دست نمی‌زنه و لاگین Anthropic رو دور نمی‌زنه.

Desktop doesn’t show the new modelsدسکتاپ مدل‌های جدید رو نمی‌بینه

Keep this terminal running. Fully quit Desktop and open it again. Confirm you picked 3P, not consumer. Then check ./claude-gateway models list. On Windows, recent Desktop builds store 3P data under %LOCALAPPDATA%\Claude-3p (MSIX: Packages\Claude_*\LocalCache), not only %APPDATA%\Claude-3p — ./claude-gateway client discover shows the path that was selected.

ترمینال این برنامه باید باز باشه. دسکتاپ رو کامل ببند و دوباره باز کن. مطمئن شو 3P رو زدی، نه حالت معمولی. بعد با ./claude-gateway models list لیست رو چک کن. روی ویندوز نسخه‌های جدید دسکتاپ کانفیگ 3P رو تو %LOCALAPPDATA%\Claude-3p می‌ذارن (نصب MSIX: Packages\Claude_*\LocalCache)، نه فقط %APPDATA%\Claude-3p — با ./claude-gateway client discover ببین کدوم مسیر انتخاب شده.

Will it overwrite my config?کانفیگ قبلی‌م پاک می‌شه؟

No. Default config is written only when none exists. Your file is left alone.

نه. کانفیگ پیش‌فرض فقط وقتی نوشته می‌شه که فایلی نباشه. فایل موجود رو دست نمی‌زنه.

Can other devices on my network use this?از دستگاه دیگه هم می‌شه زد بهش؟

Not by default. The proxy listens on 127.0.0.1 — this computer only. That’s the safe setup.

به‌صورت پیش‌فرض نه. پروکسی روی 127.0.0.1 گوش می‌ده؛ یعنی فقط همین سیستم. همین حالت، امن‌ترینه.

I don’t want the browser to openنمی‌خوام مرورگر خودش باز بشه

Start with --no-browser. The URL is still printed in the terminal.

با --no-browser اجرا کن. آدرس صفحه همچنان تو ترمینال چاپ می‌شه.

Safety, in plain terms

امنیت، به زبون ساده

  • Keys stay in environment variables, not in the config file.
  • کلیدها تو متغیر محیطی می‌مونن، نه داخل فایل کانفیگ.
  • The proxy binds to loopback. This page is served from your own process.
  • پروکسی فقط روی خود سیستم گوش می‌ده. همین صفحه هم از روی برنامه‌ی خودته.
  • Prompt capture is opt-in. Leave inspect_prompts off unless you want to read the harness.
  • ضبط پرامپت اختیاریه. inspect_prompts رو روشن نکن مگر اینکه بخوای ببینی دسکتاپ چی می‌فرسته.
