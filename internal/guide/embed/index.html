Looks like Claude Desktop. The bill doesn’t have to.

همان کلاد دسکتاپ همیشگی.
با امکان انتخاب مدل‌های ارزان‌تر دلخواه و بدون دردسر تحریم.

By default, Anthropic restricts Claude Desktop strictly to its own costly proprietary models. We broke that barrier for you: this lightweight local proxy lets you run Claude Desktop with any affordable, high-performance model you prefer (DeepSeek, Qwen, Kimi, Grok) via OpenRouter — or official Claude whenever you want.

اپلیکیشن Claude Desktop در حالت عادی کاملاً بسته است و اصلاً اجازه نمی‌دهد جز مدل‌های گران‌قیمت خود شرکت Anthropic از چیز دیگری استفاده کنید. ما این سد را برای شما شکسته‌ایم: با اجرای این برنامهٔ سبک و محلی، می‌توانید داخل همان کلاینت رسمی و زیبای Claude Desktop، مدل‌های بسیار اقتصادی‌تر، سریع‌تر و دلخواه خودتان (مثل DeepSeek ،Qwen ،Kimi و Grok) را آزادانه انتخاب کنید.

No Anthropic account login is required: Because requests do not go through Anthropic's web sign-in, your personal account will never face regional blocks, account suspensions, or sanctions when operating from Iran. بدون نیاز به ورود به اکانت کلاد: از آنجا که کلیهٔ درخواست‌ها بدون لاگین در اکانت رسمی Anthropic ردوبدل می‌شوند، حسابتان به هیچ وجه با خطرات بسته شدن، بن و تحریم‌های منطقه‌ای در ایران مواجه نخواهد شد.

Install

نصب و راه‌اندازی

Set your API key, download the binary, and run it. No git clone or build tools required. The first run creates your configuration file automatically if it doesn't exist.

ابتدا کلید API خود را مشخص کنید، سپس فایل باینری را دریافت و اجرا نمایید. نیازی به کلون کردن ریپازیتوری یا پیش‌نیازهای پیچیده نیست؛ در اولین اجرا، فایل تنظیمات به‌طور خودکار ساخته می‌شود.

export OPENROUTER_API_KEY=sk-or-...
curl -L -o claude-gateway https://github.com/Danakolana/claude-gateway/releases/latest/download/claude-gateway-linux-amd64
chmod +x claude-gateway
./claude-gateway

ARM64 Linux: download claude-gateway-linux-arm64 instead.

لینوکس ARM64: به‌جاش claude-gateway-linux-arm64 رو بگیر.

export OPENROUTER_API_KEY=sk-or-...
curl -L -o claude-gateway https://github.com/Danakolana/claude-gateway/releases/latest/download/claude-gateway-darwin-arm64
chmod +x claude-gateway
xattr -d com.apple.quarantine ./claude-gateway 2>/dev/null || true
./claude-gateway

Intel Mac: use claude-gateway-darwin-amd64. Check with uname -m.

مک اینتل: claude-gateway-darwin-amd64. با uname -m ببین کدومی.

$env:OPENROUTER_API_KEY = "sk-or-..."
curl.exe -L -o claude-gateway.exe https://github.com/Danakolana/claude-gateway/releases/latest/download/claude-gateway-windows-amd64.exe
.\claude-gateway.exe

SmartScreen may warn on an unsigned executable — click "More info", then "Run anyway" if you trust the GitHub release. Keep this terminal open while using Claude Desktop. ARM Windows: claude-gateway-windows-arm64.exe.

اگر ویندوز اخطار SmartScreen نشان داد، روی More info و سپس Run anyway کلیک کنید. مادامی که با کلاد دسکتاپ چت می‌کنید، پنجرهٔ ترمینال را باز بگذارید. نسخهٔ ARM ویندوز: claude-gateway-windows-arm64.exe.

Turn on Developer Mode in Claude Desktop

روشن کردن Developer Mode در کلاد دسکتاپ

You can turn this on directly from the Sign In screen without logging in. The Developer menu is hidden until you complete this one-time step.

این گزینه را می‌توانید حتی در همان صفحهٔ اولیه ورود (Sign In) و بدون لاگین فعال کنید. منوی Developer تا زمانی که این مرحله را یک‌بار انجام ندهید پنهان خواهد بود.

  1. Windows: click the hamburger menu ☰ at the top-left corner → Help→Troubleshooting→Enable Developer Mode. ویندوز: روی منوی همبرگری ☰ در گوشهٔ بالا-چپ پنجره کلیک کنید → Help→Troubleshooting→Enable Developer Mode.
  2. macOS: top menu bar → Help→Troubleshooting→Enable Developer Mode. مک: از نوار بالای سیستم‌عامل مسیر مقابل را انتخاب کنید: Help→Troubleshooting→Enable Developer Mode.
  3. A new Developer menu will appear. Open third-party inference settings: منوی جدیدی به نام Developer ظاهر می‌شود. تنظیمات درگاه شخص‌ثالث را باز کنید:

    Windows: hamburger ☰ → Developer→Configure Third-Party Inference…

    ویندوز: منوی همبرگری ☰ → Developer→Configure Third-Party Inference…

    macOS: Developer→Configure Third-Party Inference…

    مک: منوی Developer→Configure Third-Party Inference…

  4. Our gateway writes these Connection settings automatically on first run when you select 3P. Use this menu whenever you want to inspect or verify them. باینری ما هنگام اولین اجرا و انتخاب حالت 3P این تنظیمات را به‌صورت خودکار در سیستم ذخیره می‌کند. از این منو می‌توانید برای مشاهده و اطمینان از اعمال صحیح تنظیمات استفاده نمایید.

    How it works
    
    
    چطور کار می‌کنه
    
    
    Desktop only accepts Anthropic-looking model IDs. This gateway keeps those IDs, shows readable names in the picker, and remaps each request to the real OpenRouter model.
    
    
    دسکتاپ فقط شناسه‌هایی شبیه Claude رو قبول می‌کنه. این برنامه همون شناسه‌ها رو نگه می‌داره، تو لیست مدل اسم خوانا می‌ذاره، و هر درخواست رو می‌فرسته به مدل واقعی روی OpenRouter.
    
    
    
      
    
        
    1
    
        
    Run it locally
    
        
    روی سیستم خودت اجراش کن
    
        
    Start the binary with your OpenRouter key. This page opens in the browser. Nothing leaves your machine except the model call itself.
    
        
    باینری رو با کلید OpenRouter اجرا می‌کنی. همین صفحه تو مرورگر باز می‌شه. از سیستم خودت چیزی بیرون نمی‌ره، غیر از همون درخواستی که باید بره سمت مدل.
    
      
    
      
    
        
    2
    
        
    It wires Desktop for you
    
        
    دسکتاپ رو برات تنظیم می‌کنه
    
        
    Connection settings and model labels are written automatically for every Claude Desktop folder this app can find. You should not need to edit JSON.
    
        
    تنظیمات اتصال و اسم مدل‌ها برای هر پوشه Claude Desktop که پیدا بشه خودش نوشته می‌شه؛ لازم نیست فایل JSON رو دستی عوض کنی.
    
      
    
      
    
        
    3
    
        
    Pick a model, chat as usual
    
        
    مدل رو انتخاب کن و مثل همیشه چت کن
    
        
    Reopen Claude Desktop. The picker shows names you recognize. Cheap remaps and official Claude both live in the same list.
    
        
    دسکتاپ رو یه بار ببند و باز کن. تو لیست، اسم‌هایی می‌بینی که می‌فهمی. هم مدل ارزون هست، هم Claude رسمی — تو یه لیست.
    
      
    
    
    
  
    

  
    
    
    Why bother?
    
    
    بدون این، گیر چی می‌افتی؟
    
    
    Claude Desktop is a great client. It just wasn’t built to let you pick cheaper models, or to show you the giant prompt it ships on every turn.
    
    
    خود Claude Desktop عالیه. مشکل اینه که برای مدل ارزون ساخته نشده، و معمولاً هم نمی‌ذاره ببینی هر بار دقیقاً چه پرامپت گنده‌ای داره می‌فرسته بالا.
    
    
    
      
    
        Every turn at Anthropic prices
        هر پیام با قیمت Anthropic حساب می‌شه
        Agent chats with tools and a huge system prompt burn tokens fast on official Claude rates.
        چت‌های سنگین با ابزار و پرامپت بلند، با تعرفه‌ی رسمی Claude خیلی زود می‌سوزه.
      
    
      
    
        Desktop rejects non-Claude IDs
        مدل غیر Claude رو راه نمی‌ده
        You can’t paste deepseek/... into the picker. It wants Anthropic-shaped routes.
        نمی‌تونی deepseek/... رو بندازی تو لیست مدل. دسکتاپ فقط مسیر شبیه Anthropic می‌خواد.
      
    
      
    
        The system prompt stays invisible
        پرامپت سیستم رو نمی‌بینی
        Desktop sends a large system prompt plus tool schemas every turn. Without a proxy, you rarely see it.
        هر بار یه پرامپت بلند و لیست ابزار همراه پیام می‌ره. بدون پروکسی معمولاً خبر نداری داخلش چیه.
      
    
      
    
        No clean cheap / official switch
        سوییچ تمیز بین ارزون و رسمی نداری
        Jumping between a budget coding model and official Claude needs a local router — not config hacks.
        بین مدل ارزون کدنویسی و Claude رسمی، یه روتر روی سیستم خودت لازم داری — نه دستکاری الکی کانفیگ.

    Useful knobs
    
    
    تنظیماتی که واقعاً به درد می‌خورن
    
    
    You don’t need to touch these on day one. When you do, they live in config.toml.
    
    
    روز اول لازم نیست دست به اینا بزنی. وقتی خواستی، همه‌شون تو config.toml هستن.
    
    
    
      
    
        local vs direct
        حالت local یا direct
        
    mode = "local" (default) remaps any Desktop ID through this proxy. mode = "direct" talks to OpenRouter’s Anthropic API with no local proxy — official anthropic/claude-* only.
    
        
    mode = "local" پیش‌فرضه: هر مدل دسکتاپ از همین برنامه رد می‌شه و می‌تونه ارزون باشه. mode = "direct" بدون پروکسی محلی می‌ره OpenRouter — فقط مدل‌های رسمی anthropic/claude-*.
    
      
    
      
    
        Spend less per turn
        خرج هر پیام کمتر بشه
        
    prefer_cheapest, ensure_prompt_cache, thinking_policy, and provider sort = "price". Live prices: models status.
    
        
    prefer_cheapest ارزون‌ترین مدل مناسب رو برمی‌داره. ensure_prompt_cache سعی می‌کنه پرامپت تکراری ارزون‌تر حساب بشه. thinking_policy جلوی توکن فکر کردن اضافه رو می‌گیره. قیمت زنده: models status.
    
      
    
      
    
        OpenRouter won’t open
        اگه OpenRouter باز نشد
        
    Point at a compatible mirror with OPENROUTER_BASE_URL or [providers.openrouter] base_url in config. Same API, different host.
    
        
    می‌تونی آدرس یه آینه‌ی سازگار رو بدی: متغیر OPENROUTER_BASE_URL، یا تو کانفیگ [providers.openrouter] base_url. همون API، فقط آدرس فرق می‌کنه.
    
      
    
      
    
        Add your own model
        مدل خودت رو اضافه کن
        
    A [models.*] block needs a desktop_id that looks like claude-* or anthropic/claude-*, plus a routing rule. Re-run the binary so Desktop refreshes.
    
        
    یه بلوک [models.*] بذار. desktop_id باید شبیه claude-* یا anthropic/claude-* باشه، به‌علاوه‌ی یه قانون routing. دوباره اجرا کن تا دسکتاپ لیست رو عوض کنه.

    هر پیام، یه پرامپت سیستم بلند و لیست ابزار هم همراهشه. این صفحه همون‌ها رو از همین پروکسی محلی می‌خونه؛ وب‌سرور جدا نمی‌خواد. ضبط عمداً پیش‌فرض خاموشه.

    ضبط رو روشن کن، یه پیام از دسکتاپ بفرست، بعد تازه‌سازی:
    
    
    
      

    [proxy]
inspect_prompts = true
    
    
    
    
    Or: export CLAUDE_GATEWAY_INSPECT_PROMPTS=1 and restart.
    
    
    یا همین: export CLAUDE_GATEWAY_INSPECT_PROMPTS=1 و برنامه رو از نو اجرا کن.
    
    
    
  
    

  
    
    
    Questions people actually ask
    
    
    سؤال‌هایی که معمولاً پیش میاد
    
    
    
      
    
        Where does the API key go?کلید API رو کجا بذارم؟
        
    In the environment: OPENROUTER_API_KEY. Do not put secrets in TOML — that file is plain text on disk.
    
        
    تو متغیر محیطی: OPENROUTER_API_KEY. کلید رو نذار داخل فایل کانفیگ؛ اون فایل روی دیسک، متن ساده‌ست و برای رمز مناسب نیست.
    
      
    
      
    
        Is this patching Claude Desktop?این برنامه دسکتاپ رو هک می‌کنه؟
        
    No. It uses documented 3P gateway Connection settings. It does not patch binaries or bypass Anthropic login.
    
        
    نه. از تنظیمات رسمی حالت 3P استفاده می‌کنه. باینری Claude رو دست نمی‌زنه و لاگین Anthropic رو دور نمی‌زنه — فقط Connection شخص‌ثالث را می‌نویسد.
    
      
    
      
    
        Desktop doesn’t show the new modelsدسکتاپ مدل‌های جدید رو نمی‌بینه
        
    Keep this terminal running. Fully quit Desktop and open it again. Confirm you picked 3P, not consumer. Then check ./claude-gateway models list. On Windows, recent Desktop builds store 3P data under %LOCALAPPDATA%\Claude-3p (MSIX: Packages\Claude_*\LocalCache), not only %APPDATA%\Claude-3p — ./claude-gateway client discover shows the path that was selected.
    
        
    ترمینال این برنامه باید باز باشه. دسکتاپ را کامل ببند و دوباره باز کن. مطمئن شو 3P را زدی، نه حالت معمولی. بعد با ./claude-gateway models list لیست را چک کن.

    روی ویندوز نسخه‌های جدید، کانفیگ 3P معمولاً زیر %LOCALAPPDATA%\Claude-3p است (نصب MSIX: Packages\Claude_*\LocalCache)، نه فقط %APPDATA%\Claude-3p. با ./claude-gateway client discover ببین کدام مسیر انتخاب شده.
    
      
    
      
    
        Will it overwrite my config?کانفیگ قبلی‌م پاک می‌شه؟
        
    No. Default config is written only when none exists. Your file is left alone.
    
        
    نه. کانفیگ پیش‌فرض فقط وقتی نوشته می‌شه که فایلی نباشه. اگر فایل از قبل هست، دستش نمی‌زنه.
    
      
    
      
    
        Can other devices on my network use this?از دستگاه دیگه هم می‌شه زد بهش؟
        
    Not by default. The proxy listens on 127.0.0.1 — this computer only. That’s the safe setup.
    
        
    به‌صورت پیش‌فرض نه. پروکسی روی 127.0.0.1 گوش می‌ده؛ یعنی فقط همین سیستم. همین حالت امن‌ترینه و ترافیک شبکه محلی را باز نمی‌کند.
    
      
    
      
    
        I don’t want the browser to openنمی‌خوام مرورگر خودش باز بشه
        
    Start with --no-browser. The URL is still printed in the terminal.
    
        
    با --no-browser اجرا کن. آدرس صفحه همچنان تو ترمینال چاپ می‌شه تا خودت بازش کنی.
    
      
    
      
    
        It says NOT READY / PARTIALمی‌گه NOT READY یا PARTIAL
        
    Read the FAIL/WARN lines. The usual fix is exporting OPENROUTER_API_KEY in the same terminal. If that is not enough, click Copy report prompt above and send it to whoever gave you this app.
    
        
    خط‌های FAIL / WARN را بخوان. معمولاً باید OPENROUTER_API_KEY را در همان ترمینال export کنی. اگر کافی نبود، دکمه کپی پرامپت گزارش را بزن و برای کسی که برنامه را فرستاده بفرست.
