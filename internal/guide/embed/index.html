What breaks without this

اگه این نباشه، چی؟

Claude Desktop is excellent — until you want other models, lower cost, or visibility into what it actually sends upstream.

Claude Desktop عالیه — تا وقتی بخوای مدل دیگه، هزینه کمتر، یا ببینی دقیقاً چی می‌فرسته بالا.

Locked to Anthropic billing قفل روی قبض Anthropic Heavy agent turns with tools + huge system prompts burn tokens fast on official Claude rates. چت‌های سنگین با ابزار و سیستم‌پرامپت گنده، با تعرفه رسمی Claude سریع می‌سوزه.
Desktop rejects non-Claude model IDs Desktop مدل غیر Claude رو قبول نمی‌کنه You can’t just paste deepseek/... into the picker. Desktop wants Anthropic-looking routes. نمی‌تونی فقط deepseek/... رو بندازی تو انتخابگر؛ Desktop مسیر شبیه Anthropic می‌خواد.
Invisible system harness سیستم‌پرامپت مخفی Desktop ships a large system prompt + tool schemas every turn. Without a proxy you rarely see it. Desktop هر بار یه سیستم‌پرامپت گنده + لیست ابزار می‌فرسته؛ بدون پروکسی معمولاً نمی‌بینیش.
No clean remap / fallback story سوییچ تمیز بین مدل‌ها نداری Switching between budget coding models and official Claude needs a local router — not manual config hacks. سوییچ بین مدل‌های ارزون کدنویسی و Claude رسمی یه روتر محلی می‌خواد، نه هک دستی کانفیگ.

What this gateway does

این گیت‌وی چیکار می‌کنه؟

Configures Claude Desktop (3P) so the model picker shows friendly labels while IDs stay Anthropic-shaped.

Claude Desktop (حالت 3P) رو جوری تنظیم می‌کنه که لیبل‌های خوانا ببینی، ولی IDها شبیه Anthropic بمونن.

Runs a loopback Anthropic Messages proxy that remaps those IDs to OpenRouter (or a compatible mirror) — DeepSeek, Kimi, Qwen, Grok, official Claude, and more.

یه پروکسی محلی Messages راه می‌ندازه و اون IDها رو به OpenRouter (یا آینه سازگار) مپ می‌کنه — DeepSeek، Kimi، Qwen، Grok، Claude رسمی و بیشتر.

Install

نصب

Download the binary for your OS. No checkout required — first run writes the default config automatically.

باینری سیستم‌عاملت رو بگیر. لازم نیست ریپو کلون کنی — اولین اجرا خودش کانفیگ پیش‌فرض رو می‌نویسه.

curl -fsSL -o claude-gateway \
  https://github.com/Danakolana/claude-gateway/releases/latest/download/claude-gateway-linux-amd64
chmod +x claude-gateway
export OPENROUTER_API_KEY=sk-or-...
./claude-gateway
curl -fsSL -o claude-gateway \
  https://github.com/Danakolana/claude-gateway/releases/latest/download/claude-gateway-darwin-arm64
chmod +x claude-gateway
xattr -d com.apple.quarantine ./claude-gateway 2>/dev/null || true
export OPENROUTER_API_KEY=sk-or-...
./claude-gateway
Invoke-WebRequest -Uri "https://github.com/Danakolana/claude-gateway/releases/latest/download/claude-gateway-windows-amd64.exe" `
  -OutFile "claude-gateway.exe"
$env:OPENROUTER_API_KEY = "sk-or-..."
.\claude-gateway.exe

First run

اولین اجرا

  1. Set OPENROUTER_API_KEY and start the binary. This guide opens in your browser; the terminal prints the same URL. OPENROUTER_API_KEY رو بذار و باینری رو اجرا کن. این راهنما تو مرورگر باز می‌شه؛ همون آدرس تو ترمینال هم چاپ می‌شه.
  2. Choose 3P when asked (recommended). Desktop Connection settings are written for you. وقتی پرسید، 3P رو بزن (پیشنهادی). تنظیمات Connection دسکتاپ برات نوشته می‌شه.
  3. Reopen Claude Desktop (or Apply Changes). Pick a labeled model — budget remaps or official Claude. Claude Desktop رو دوباره باز کن (یا Apply Changes). مدل برچسب‌دار رو انتخاب کن — remap ارزون یا Claude رسمی.

Config path: ~/.config/claude-gateway/config.toml (Windows: %APPDATA%\claude-gateway\config.toml). Existing files are never overwritten.

مسیر کانفیگ: ~/.config/claude-gateway/config.toml (ویندوز: %APPDATA%\claude-gateway\config.toml). فایل موجود رو دست نمی‌زنه.

Harness & system prompts

Harness و سیستم‌پرامپت

Claude Desktop sends a large system prompt and tool list on each turn. This page reads them from the same local proxy — no extra web server.

Claude Desktop هر بار یه سیستم‌پرامپت گنده و لیست ابزار می‌فرسته. این صفحه همون رو از پروکسی محلی می‌خونه — بدون وب‌سرور جدا.

inspect off

Enable capture (off by default for privacy), then use Desktop once and refresh:

برای حریم خصوصی پیش‌فرض خاموشه. روشنش کن، یه‌بار با Desktop حرف بزن، بعد Refresh:

[proxy]
inspect_prompts = true

Or: export CLAUDE_GATEWAY_INSPECT_PROMPTS=1 then restart.

یا: export CLAUDE_GATEWAY_INSPECT_PROMPTS=1 و ری‌استارت.

Useful knobs

تنظیمات به‌دردبخور

mode = "local" (default) remaps any Desktop ID. mode = "direct" talks to OpenRouter’s Anthropic API without the local proxy — official anthropic/claude-* only.

mode = "local" (پیش‌فرض) هر ID دسکتاپ رو remap می‌کنه. mode = "direct" بدون پروکسی محلی می‌ره سراغ API سازگار Anthropic تو OpenRouter — فقط anthropic/claude-*.

Cost helpers: prefer_cheapest, ensure_prompt_cache, thinking_policy, provider sort = "price". See models status in the terminal for live prices.

کمک‌هزینه: prefer_cheapest، ensure_prompt_cache، thinking_policy، و sort = "price". قیمت زنده تو ترمینال: models status.

Served from your local proxy · loopback only · secrets stay in env vars از پروکسی محلی سرو می‌شه · فقط loopback · کلیدها تو env می‌مونن
